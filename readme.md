# KIET Galaxy Gym Website 🏋️‍♂️

A fully functional, responsive, and user-friendly fitness and gym website designed specifically for hostel students as part of the Mid-Semester Examination (MSE) Web Development and Cloud Foundation project.

---

## 🎯 Objective
To develop a professional web application representing a campus gym facility ("KIET Galaxy Gym") featuring robust layouts, interactive features, high-quality visuals, and clean HTML5, CSS3, and JavaScript implementation.

---

## ✨ Features
- **Modern UI/UX Design:** Built with a clean, engaging fitness-themed color palette, smooth shadows, and responsive grid layouts.
- **Exclusive Hostel Access Info:** Clearly highlights designated student schedules and campus residency access policies.
- **Service & Program Showcases:** Detailed breakdowns of strength training, cardio zones, hypertrophy programs, and fat-loss conditioning routines.
- **Interactive JavaScript Form:** A dynamic membership inquiry selector providing instant feedback alerts for students.
- **Fully Responsive:** Adapts seamlessly across mobile phones, tablets, and desktop displays.

---

## 🛠️ Technologies Used
- **HTML5:** Semantic document structure and markup.
- **CSS3:** Flexbox, CSS Grid, Google Fonts (`Poppins`), and responsive media queries.
- **JavaScript (ES6):** Basic client-side interaction and event handling.
- **Hosting & Version Control:** Git, GitHub, and Vercel.
